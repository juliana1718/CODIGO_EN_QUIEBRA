2. Lenguajes de programación

HTML

Permite construir la estructura de una página web.

CSS

Permite diseñar la apariencia, los colores y la distribución de una página web.

JavaScript

Permite agregar interactividad y comportamiento a las páginas web.

Python

Es un lenguaje utilizado para desarrollar programas, automatizar procesos y trabajar con datos.

3. Ejemplo de programación en Python

Programa que solicita el nombre y muestra un saludo:

nombre = input("Escribe tu nombre: ")

print("Bienvenido a Código En Quiebra", nombre)

4. Ejercicios prácticos

Ejercicio 1. Variables

Crea un programa que solicite el nombre y la edad de una persona y muestre sus datos.

Ejercicio 2. Condicionales

Solicita una edad y determina si la persona es mayor o menor de edad.

Ejercicio 3. Ciclos

Realiza un programa que muestre los números del 1 al 10.

Ejercicio 4. Operaciones

Solicita dos números y calcula su suma, resta, multiplicación y división.

5. Aplicación en el mundo laboral

  • Desarrollo de software.
  • Creación de aplicaciones web.
  • Automatización de actividades.
  • Análisis y procesamiento de información.
  • Desarrollo de soluciones tecnológicas.
